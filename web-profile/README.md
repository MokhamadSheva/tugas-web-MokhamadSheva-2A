# Web Profile - Mokhamad Sheva (Kelas 2A)

Website Profil pribadi sederhana, modern, dan responsif yang dibangun menggunakan **Tailwind CSS**.

## ✨ Fitur
- **Responsive Design**: Tampilan optimal di HP, tablet, maupun laptop/desktop.
- **Hero & Profile Section**: Menampilkan foto profil, nama, status mahasiswa/developer, dan link aksi.
- **About Me**: Ringkasan biodata diri, fokus minat belajar, dan status.
- **Skills Grid**: Menampilkan badge teknologi (HTML5, CSS3, Tailwind CSS, JS, Git/GitHub, Responsive UI).
- **Projects / Portofolio**: Kartu proyek untuk memamerkan tugas-tugas kuliah.
- **Contact & Social Media**: Form pesan interaktif dan tautan GitHub/Email/Sosial Media.

## 🖼️ Cara Mengganti Foto Profil
1. Siapkan foto profil kamu (misalnya bernama `profile.png` atau `profile.jpg`).
2. Masukkan ke dalam folder `img/` (misalnya `img/profile.png`).
3. Jika nama filenya berbeda, sesuaikan baris `src="img/profile.png"` pada file `index.html`.

## 🚀 Menjalankan Web
Cukup klik ganda (double-click) file `index.html` atau buka menggunakan ekstensi *Live Server* di VS Code.
